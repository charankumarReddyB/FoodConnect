# FOODCONNECT — MASTER FIGMA AI PROMPT

Design the **complete UI/UX** for a production-ready cross-platform application called **FoodConnect**.

FoodConnect is a location-based food donation platform that connects food donors with nearby orphanages, old-age homes, shelters, NGOs, and community volunteers to reduce food wastage.

This is **NOT** a college project UI.

Design it as if it is a real startup product preparing for launch on Android, iOS, and the Web.

The final design should be polished enough to present to investors, NGOs, incubators, government organizations, and professional software developers.

---

## OBJECTIVE

Create a **complete, production-quality frontend** including:

* Android Mobile App
* iOS App
* Responsive Tablet Layout
* Responsive Desktop Web Application

Use **one unified design system** shared across every platform.

Do not generate only a mobile app.

Every important screen must include:

* Mobile Layout
* Tablet Layout
* Desktop Layout

---

## IMPLEMENTATION TARGET

The UI will later be implemented using **Flutter**.

Design every layout to be Flutter-friendly and responsive.

Avoid impossible layouts.

Use responsive grids and reusable components.
